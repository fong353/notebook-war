## 我为什么做这个

小时候我在练习本的边角上画战争。两边都是坦克和飞机，铅笔线当曳光弹，谁被打中就在上面划一道。
从来没有规则——我只是想看两边互相打，哪一方要输了就再给它加一辆坦克。

这就是那张涂鸦，重做成一个自己会运转的东西。你不指挥任何人。你把部队画到纸上，它们自己开打；
你就算再也不碰它，这场仗照样打完。当年喜欢的东西都还在——看着像圆珠笔画在方格纸上，每个单位
带血条，陆空互相开火。

当年**不会画**的东西，就是代码要做的事：步兵被机枪压得抬不起头、爬进壕沟；坦克被打断履带开始
冒烟；俯冲轰炸机得飞一趟真正的攻击航线，而不是悬在目标头顶。

## 这是什么

一个 HTML 文件。没有构建步骤、没有依赖、不发任何网络请求——打开就能跑。

- **两个年代。** `index.html` 是 1944：德军、美军、苏军，任选两家对打。
  `cold-war.html` 是早先那版：美苏对抗，有直升机、无人机和巡航导弹。
- **中英双语。** 界面右下角一个按钮切换，型号名也跟着换（`Pz.VI 虎式` ↔ `Pz.VI Tiger`）。
- **16 个兵种**，每国用各自的真实装备——虎式、谢尔曼、T-34 是三种不同的轮廓，不是同一个方块换三种颜色。
- **武器是独立的东西。** 一个单位挂一两门，各有射程、装填和弹药，开火时按"对当前目标的有效伤害"
  自己挑：坦克碰步兵用同轴机枪、碰装甲才动主炮；战斗机贴身缠斗只能用机枪，因为导弹有最小射程。
- **压制决定步兵战。** 弹片落在身边就压得人抬不起头，不需要命中。被压住的步兵会往最近的壕沟或
  碉堡里爬，停止推进。
- **坦克会断履带冒烟；老兵挂星、也更早撤下来；伤重的会退回后方整补，卫生兵和补给车会跟上去。**
- **六个指挥官指令**（空袭 / 炮击 / 增援 / 鼓舞 / 烟雾 / 空降），带冷却——让你能干预战局，
  又不用当保姆。

## 怎么玩

[在线试玩](https://fong353.github.io/notebook-war/?lang=zh)，或者把仓库拉下来直接打开 `index.html`——
不需要服务器，不需要构建。

- 在战场上按住拖动＝画出部队。点一个指令，再点战场选位置。
- 光标停在任何单位上，能看到它的型号、武器、余弹和当前状态。
- `空格`暂停，数字/字母键选兵种，`Tab` 把画笔交给对方。
- 手机上有**横屏**按钮——战场当然是越宽越好。
- URL 参数：`?warmup=45` 直接跳到交战中（不然看到的总是还没接触的开局）；
  `?units=38` 把每方编制从默认 17 提到 38，配宽屏摆大军；`?lang=en` 指定语言。

## 几处实现上的笔记

有几个决定比预想的更要紧：

**作弊透视。** 地面是真的单点透视网格，但单位缩放故意不是。真透视会把远处压到 47%，就看不清了；
完全不压，纵深又消失。最后定在约 62%。

**固定翼飞机不能用收敛式移动。** 用 `(目标 - 自己) / 距离` 来导引看着没问题，直到你注意到那个
距离是三维的：一架 95 高度的飞机飞到地面坦克正上方时，还有 95 的间隔，于是分子趋零而分母不趋零，
飞机就减速悬停在目标头顶。攻击航线改成用航段计数驱动——飞这么远、脱离、掉头、再回来——
不管目标怎么动都不会卡死。

**让战斗好看，关键不在于放慢射速。** 火力稀疏只会让画面沉闷。需要的是单位能活过第一轮交火，
双方才会缠在一起：更厚的血、突击兵种顶到近距离、以及给导弹加最小射程，让贴身战退回机枪对射。

**弹坑靠"每隔一会儿把整层伤痕擦掉一点"来淡出**，而不是给每个坑存生命值再逐帧重画。老坑被擦的
次数多，所以先消失。
