## 我为什么做这个

小时候我在练习本的边角上画战争。两边都是坦克和飞机，铅笔线当曳光弹，谁被打中就在上面划一道。
从来没有规则——我只是想看两边互相打，哪一方要输了就再给它加一辆坦克。

这就是那张涂鸦，重做成一个自己会运转的东西。你不指挥任何人。你把部队画到纸上，它们自己开打；
你就算再也不碰它，这场仗照样打完。当年喜欢的东西都还在——看着像圆珠笔画在方格纸上，每个单位
带血条，陆空互相开火。

当年**不会画**的东西，就是代码要做的事：步兵被机枪压得抬不起头、爬进壕沟；坦克被打断履带开始
冒烟；俯冲轰炸机得飞一趟真正的攻击航线，而不是悬在目标头顶。

## 这是什么

一个 HTML 文件。没有构建步骤、没有依赖、不发任何网络请求——打开就能跑。

- **四套设定。** `ww1.html` 是 1918——英军、法军、德军，也是工事系统真正当主角的那一套：
  铁丝网把步兵挂住、坦克照压过去；毒气云会飘、会持续伤人；徐进弹幕一排排向前推；
  菱形的 Mk.IV、福克三翼机，还有天上的齐柏林飞艇。两个关于"过时战术"的奇观也在这一版：
  一个营越出战壕、按命令以行进速度走过无人区，因为炮击本该把铁丝网削平；以及一支只在敌方
  阵线真被打薄时才出现的骑兵——那个骑兵师等了四年、几乎没等到的缺口。
  `index.html` 是 1944：德军、美军、苏军，任选两家对打。
  `cold-war.html` 是美苏对抗，有直升机、无人机和巡航导弹。
  `starwars.html` 是银河帝国 / 义军同盟 / 银河共和国——坦克换成步行机，
  AT-AT 迈着四条分节长腿走过来，钛战机顶着两片六边形板悬在头上。
- **中英双语。** 界面右下角一个按钮切换，型号名也跟着换（`Pz.VI 虎式` ↔ `Pz.VI Tiger`）。
- **十六七个兵种**，每国用各自的真实装备——虎式、谢尔曼、T-34 是三种不同的轮廓，不是同一个方块换三种颜色。
- **武器是独立的东西。** 一个单位挂一两门，各有射程、装填和弹药，开火时按"对当前目标的有效伤害"
  自己挑：坦克碰步兵用同轴机枪、碰装甲才动主炮；战斗机贴身缠斗只能用机枪，因为导弹有最小射程。
- **压制决定步兵战。** 弹片落在身边就压得人抬不起头，不需要命中。被压住的步兵会往最近的壕沟或
  碉堡里爬，停止推进。
- **坦克会断履带冒烟；老兵挂星、也更早撤下来；伤重的会退回后方整补，卫生兵和补给车会跟上去。**
- **奇观会自己来。** 每隔一分来钟就有超规格的东西不请自来：V-2 毫无预警地砸下来、拦都拦不住；
  V-1 慢得让高炮有机会打下来；还有 B-17 编队、喀秋莎全营齐射。1918 有自己的一套——齐柏林夜袭、
  巴黎大炮、列车炮弹幕、越顶冲锋、骑兵突击。每样都归属某一国，只有那国上场才见得到。
- **六个指挥官指令**（空袭 / 炮击 / 增援 / 鼓舞 / 烟雾 / 空降），带冷却——让你能干预战局，
  又不用当保姆。

## 怎么玩

[在线试玩](https://fong353.github.io/notebook-war/?lang=zh)，或者把仓库拉下来直接打开 `index.html`——
不需要服务器，不需要构建。

- 在战场上按住拖动＝画出部队。点一个指令，再点战场选位置。
- 光标停在任何单位上，能看到它的型号、武器、余弹和当前状态。
- `空格`暂停，数字/字母键选兵种，`Tab` 把画笔交给对方。
- 手机上有**横屏**按钮——战场当然是越宽越好。
- URL 参数：`?warmup=45` 直接跳到交战中（不然看到的总是还没接触的开局）；
  `?units=38` 把每方编制从默认 17 提到 38，配宽屏摆大军；`?lang=en` 指定语言。

## 几处实现上的笔记

有几个决定比预想的更要紧：

**作弊透视。** 地面是真的单点透视网格，但单位缩放故意不是。真透视会把远处压到 47%，就看不清了；
完全不压，纵深又消失。最后定在约 62%。

**固定翼飞机不能用收敛式移动。** 用 `(目标 - 自己) / 距离` 来导引看着没问题，直到你注意到那个
距离是三维的：一架 95 高度的飞机飞到地面坦克正上方时，还有 95 的间隔，于是分子趋零而分母不趋零，
飞机就减速悬停在目标头顶。攻击航线改成用航段计数驱动——飞这么远、脱离、掉头、再回来——
不管目标怎么动都不会卡死。

**让战斗好看，关键不在于放慢射速。** 火力稀疏只会让画面沉闷。需要的是单位能活过第一轮交火，
双方才会缠在一起：更厚的血、突击兵种顶到近距离、以及给导弹加最小射程，让贴身战退回机枪对射。

**装甲得分成两级，数值才能说实话。** 原本每件武器只有一个对装甲倍率，而飞机也被标成装甲
单位——于是同一个数字既决定"这挺机枪能不能打赢空战"，又决定"它能不能凿穿坦克"。战斗机机枪
必须给得够高才打得动空战，代价是它顺手也能把虎式打穿。把装甲拆成两级——飞机和轻装甲车辆
一级、坦克另一级——机枪对坦克才能彻底归零而不伤及空战，坦克这才有了坦克的分量。

**弹坑靠"每隔一会儿把整层伤痕擦掉一点"来淡出**，而不是给每个坑存生命值再逐帧重画。老坑被擦的
次数多，所以先消失。

## 致谢

这东西是在与 **Claude Opus 5** 的对话里做出来的。我描述了小时候画的那张涂鸦，它写出了第一版；
之后一轮一轮来——我指出哪里不对（"喷气机得来回飞"、"缠斗结束得太快"、"血条和载具重合了"），
它改完，再把实测数据摆给我看，证明这一改到底管不管用。

我没想到的是，真正的原因常常不在我指的那个地方。压制显得弱，不是数值低，而是伤亡把兵力磨到只剩
14 个、火力压根密集不起来；缠斗短命，不是机炮太狠，而是导弹没有最小射程，58 点伤害在贴身距离照样能放；
飞机不肯飞攻击航线也不是犯倔——用三维距离来导引，会让飞机在目标正上方减速到悬停。这三处都是它
靠给模拟加埋点、读实测输出找出来的，不是猜的；我要求的改动破坏了别的机制时，它也会直说。
commit 历史是这一切的诚实记录。
